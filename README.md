# Valutatrade Hub

**Valutatrade Hub** - это консольное приложение, имитирующее работу валютного кошелька. 
Проект позволяет пользователям регистрироваться, управлять виртуальным портфелем фиатных денег и криптовалют, а также совершать сделки по покупке и продаже активов по актуальным курсам.

## Основные возможности
- Регистрация и авторизация пользователей с безопасным хешированием паролей.
- Просмотр портфеля с автоматическим пересчетом в базовую валюту.
- Покупка и продажа валют.
- Получение актуальных курсов валют.
